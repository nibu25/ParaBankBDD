# ParaBank BDD Automation Framework

## Project Overview
This project automates the ParaBank demo application using Selenium WebDriver and Cucumber BDD.

## Technologies Used
- Java
- Selenium WebDriver
- Cucumber BDD
- Maven
- TestNG
- Page Object Model (POM)
- IntelliJ IDEA
- Git and GitHub

## Framework Structure
- `features` – Cucumber feature files
- `Stepdef` – Step definition classes
- `pages` – Page Object classes
- `DriverFactory` – WebDriver initialization
- `Hooks` – Before and After hooks
- `Utils` – Configuration utilities

## Execution
Run the Cucumber test scenarios using the configured TestNG runner or IntelliJ IDEA.
